# 📖 vaultの使い方

> 困った時・「今日は何しようかな」という時に開く1枚。長い説明を思い出さなくていいように、ここだけ見れば足りるようにしてある。

## 🎛 迷ったらまずこれ

| こういう時 | 呼ぶもの |
|---|---|
| 使い方をひととおり体験したい（初回） | `/tutorial` |
| 何ができるか忘れた・スキル名を覚えてない | `/menu` |
| どれから手をつけるか分からない・重くて動けない | `/next` |
| 今日・今週の時間割を組みたい | `/schedule` |
| 5分だけ自分の状態を見たい | `/check-in` |
| タスクを棚卸ししたい（期限切れ・停滞の整理） | `/audit-tasks` |
| アイデアを壁打ちしたい（結論は求めない） | `/discuss` |
| 目標・プロジェクトを分解したい | `/plan` |
| 曖昧なノートを一緒に精緻化したい | `/scan` |
| 1週間を振り返りたい | `/weekly-review` |
| 運用そのものを見直したい | `/ops-review` |

普通に喋りかけるだけでも、内容に応じて適切なところへ誘導される。スキル名を覚える必要はない。

## 🗂 どこに何があるか（超要約）

| 場所 | 中身 |
|---|---|
| `02_Home/Home.md` | 朝のサマリー・今の状況 |
| `04_Tasks/タスク管理.md` | タスク一覧 |

**迷ったらインボックスに投げ込めばいい**。分類はAIが後でやる。

## 🤖 誰が何をしてくれるか（超要約）

普段は特に呼ばなくてよい。裏で自動的に動いている（毎朝のスタンドアップ・インボックス振り分け・週次レビューの下準備など）。困った時だけ `@<名前>` で直接呼べる。**コア4体**が最初から入っている：

- **orchestrator** — タスク振り分け・スタンドアップ全般
- **researcher** — 旅行・購入・比較の具体調査
- **knowledge** — URLや資料をナレッジ化
- **infrastructure** — タスクDB棚卸し・故障監視（検出・提案のみ）

自分の生活に合わせて**専門エージェントを足せる**（家計・語学・人間関係など）。作り方は `docs/AGENTS.md`。詳しい仕様は常に `.claude/agents/<名前>.md` が正式な定義。

## ⏰ 裏で自動的に回っているもの（設定した場合）

スケジュール起動を組めば、以下が無人で回る（`docs/AUTOMATION.md` で設定）：

- 毎朝: モーニングスタンドアップ（`Home.md` に届く）
- 数時間おき: インボックス振り分け
- 昼: タスクディスパッチ（AI同士でタスクが進む便）
- 週次: 週次データ準備（レビュー自体は `/weekly-review` で対話的に）
- 毎日: `vault_lint.py` による決定的QA（`99_System/qa/` に出力）

全部見たい時は `CLAUDE.md` の「⚙️ スケジュール起動」表。
