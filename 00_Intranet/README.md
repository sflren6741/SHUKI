## 🧹 QA はどこが担うか

専任レビュアーは置かず、品質保証を分散させている：

- **セルフQA** — 各エージェント・スキルが出力末尾に3行（事実チェック／トーン／アンチスロップ）
- **オーナー確認** — 🔴ゾーン（お金・健康・外部送信）・代筆禁止ゾーン
- **決定的 lint** — `scripts/vault_lint.py`（Python・LLM不使用）が frontmatter・status・date 等を機械チェックし `99_System/qa/` に出力

詳細 → [🔄 QAサイクル](./AI運用ルール集（イントラ）/🔄%20QAサイクル.md)。任意で Ollama 等のローカルLLMを補助レイヤーに足すこともできる（ただし**明文化済みルールのチェックは決定的コードで行う**のが教訓）。

## 🤖 動き方の原則

- **自分の担当ページだけ読む**。イントラ全文を読み込まない（ハルシネーション防止）
- **タスクは `04_Tasks/` を参照**（自律ピック条件は ✅ タスク管理ルール）
- **役割の境界線を守る**（何をしないかを明示）
