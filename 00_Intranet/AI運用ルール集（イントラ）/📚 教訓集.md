# 📚 教訓集

> [!note] 📚
>
> **失敗を1回で済ませるためのファイル。** エージェント・スキル・Claude Code 本体が失敗を解消したら、ここに教訓を1エントリ残す（[[🛑 停止ルール（ストップ条件）]]）。経験がチャットと共に消えず、次のセッション・別のエージェントに物理的な文書として引き継がれる。
>
> ⚙️ **このファイルは空のテンプレートです。** 中身はあなたの環境で実際に起きたことで埋まっていきます。**最初は空のままで正しい**（他人の失敗を並べても、あなたのAIの判断は変わりません）。

## なぜこれが効くのか

AIとの作業では、同じ失敗が別のセッションで繰り返されます。チャットの文脈は消えるからです。**失敗を文書としてvaultに置く**と、次に起動したAIがそれを読んで同じ轍を避けられます。ルールファイルへの昇格ルートを持たせることで、「気づき」が「仕組み」に育ちます。

## 書き方（事実ベース限定）

新しいエントリは**上に追加**する。1エントリは以下の3行だけ：

- **起きたこと**: エラー原文の要点・事実のみ（推測の原因論を書かない）
- **効いた対策**: 実際にやって直った操作（一般論の再発防止策を書かない）
- **適用範囲**: どの作業・ファイル・エージェントで再発しうるか

同種の教訓が3件たまったらルールファイル本体への昇格を検討する。昇格したらエントリ末尾に「→ 昇格済: <ルールファイル名>」を付記し、以後の重複記録はしない。

> ⚠️ **インシデントを書くときは値でなく形で書く。** 「何が漏れたか」を記録する際に、漏れた値そのもの（トークン・ホスト名・鍵）を本文に書かないこと。`<host>.example.net` のように形だけ書けば再現には足ります。**この教訓集自体が公開・共有される可能性がある**ためです。
