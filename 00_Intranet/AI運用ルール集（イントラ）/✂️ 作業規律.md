# ✂️ 作業規律（シンプル第一・検証で完了）

> [!note] ✂️
>
> **AIにありがちな「過剰生成」「当てずっぽうの完了報告」を防ぐための規律。** Karpathy 流「コーディングAIエージェントの10のルール」を vault 向けに翻案して導入（2026-07-04）。出典と採用判断 → [[コーディングAIエージェント10のルール（Karpathy流）]]。
>
> 適用範囲：**§1 = 全ファイル（日本語の書き込み含む）**、**§2 = コード（PS1 / Python / フック等）のみ追加適用**。

## §1 全ファイル共通（文章・frontmatter・コードすべて）

### 1.1 シンプル第一（構造の水増し禁止）

- 求められていない追記・予測的なセクション・過剰な見出し構造・テンプレの先回り拡張を足さない。課題を解決する**最小限の記述**だけを出力する
- [[デザイン言語]] のアンチスロップが「文体の水増し」を縛るのに対し、これは「構造の水増し」を縛る（補完関係）

### 1.2 構造の追加は負債として警戒する

新しい frontmatter プロパティ・status 値・フォルダ・ファイル様式を vault に増やす前に、まず「**既存の構造で代替できないか**」を自問する。どうしても増やす場合は、理由と決定を [[🏁 変更ログ＆運用ルール]] に記録する（[[📋 エージェント共通テンプレート]] §作成前ルールの構造版）。

### 1.3 検証で完了を定義する

- 「直した気がする」「これで動くと思います」で完了と言わない。**機械的に検証できるもの（YAML パース・リンク実在・構文チェック・実行結果）は検証してから完了と報告する**
- 報告には**検証済みか未検証かを明示**する。不確実な点は「〜がドキュメントから確認できないため確信が持てない」のように、次のアクションに繋がる形で報告する（無根拠な安心感を提供しない）

### 1.4 依頼範囲外の扱い

- 文章・ノートの依頼範囲外の書き換えは**禁止しない**（ただの言語であり、書き換えてもバグにならない — ユーザー決定 2026-07-04。コードは §2.1 のとおり別扱い）
- ただし従来ルールが優先される：**確認必須ファイルの更新確認**（AGENTS.md §📜 ルール10: Identity / 哲学・価値観 / デザイン言語 / Areas ハブ）と**代筆禁止ゾーン**は、この項による解禁ではない
- 修正の規模が膨らみ始めたら泥沼パターンとして停止する（[[🛑 停止ルール（ストップ条件）]] §S.1-8）

## §2 コード固有の追加規律（PS1 / Python / フック）

コードは書き換えがバグを生むため、§1 より厳しい制約を追加する。

### 2.1 ピンポイントの変更（Surgical Changes）

- 変更は**要求に直接紐づく行だけ**に限定する。隣接コードの「ついで修正」「ついで整形」をしない
- 自分の変更で不要になった import・変数のみ削除してよい。無関係な既存コードには触れない

### 2.2 最小限のコード

- 単発スクリプトに不要な抽象化・共通化をしない。求められていない予測的な機能を実装しない
- 半分の行数で書けるなら書き直す（行数は目安。BOM・エラー処理・可読性を犠牲にしてまで縮めない）

### 2.3 再現 → 修正 → 検証合格で完了

- バグ修正は、まず**そのバグを確実に再現**してから直す（当てずっぽうの「自信に満ちた誤診」を防ぐ）
- エラーメッセージ・スタックトレースは**全文読む**（要約で流さない）。一度に動かす変数は**1つだけ**
- 修正後は構文チェック・実行検証が通って初めて完了とみなす（PS1 は構文エラー0＋BOM維持の確認まで）

### 2.4 依存関係は負債

- パッケージ追加の前に「**標準ライブラリで代替できないか**」を自問する
- 追加する場合は理由と決定を変更ログに記録する（前例: scipy=vault成長GIF・faster-whisper=音声文字起こし）

### 2.5 vault 固有の既存慣行（明文化）

- **日本語入り PS1 は UTF-8 BOM 付きで保存する**（PowerShell 5.1 が文字化けで構文エラーになる。[[📚 教訓集]] から昇格）
- **non-fatal 設計**: 定期実行スクリプトに機能を足すときは、その機能の失敗が本体を落とさない形にする（例: weekly_review.ps1 のレポート生成、briefing.ps1 のラジオ生成）
- **明文化済みルールのチェックは LLM でなく決定的コードで行う**（Local AI 夜間QA廃止 → vault_lint.py の教訓）
