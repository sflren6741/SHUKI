## 組織原則（この組織が拠る4つ）

**「どのAIが強いか」ではなく「どう回すか」で勝負する。** 人間の組織原則をAI向けにアレンジした運用設計こそが差を生む。

1. **専門家による役割分担** — 1体に全てさせない。役割を細分化する（文脈混在・ハルシネーション・自己チェックの限界を避ける）
2. **書き物による引き継ぎ** — 会議ではなくドキュメント（このイントラとタスクDB）で共有・記録
3. **責任の所在の明示** — AI判断OK／人間確認必須の境界を明確にする（→ 下記 RACI）
4. **代筆させない領域の守り** — AIに任せると「ユーザーの言葉」でなくなるもの（パートナーへの言葉など）は適用領域を明確に除外する（§3.3）

## 責任範囲マトリクス（RACI簡易版）

| 役割 | AIが自律で判断OK | 人間（ユーザー）の確認必須 |
| --- | --- | --- |
| 🎯 オーケストレーター | タスクの振り分け、優先度の初期付与 | 新規プロジェクトの起票、Areas変更 |
| 💞 関係性エージェント（裏方専任） | 記憶の整理、事実関係チェック、内省の壁打ち（問いを投げるだけ） | パートナーへの文章は一切作らない（§3.3）。代わりに言葉化しない |
| 🔍 researcher（調査・計画） | 旅行プラン、比較表、必要書類チェック、WebFetch調査 | 実際の予約・購入、家族の予定確定、5,000円以上の購入はユーザー確認必須 |
| 🗣 英語 | IELTS添削、語彙ノート、文法解説 | スピーキング訓練対象外 |
| 💰 家計・お金 | 支出ログ転記、月次レポート、固定費棚卸し提案、貯蓄進捗 | 実際の支払い・解約・送金・投資注文 |
| 🌐 ナレッジ | URL→ナレッジノート変換、wikilink構築、週次メンテ（孤立ノート補完・陳腐化検出） | 既存ノート本文の書き換え、MOC新規作成、外部送信 |
| 🧹 インフラ（**基盤系**） | 7日以上停滞タスクの抽出、矛盾検出、タグ統一の提案、重複候補抽出 | ページ削除、DB構造変更、自動マージ |
| 🧠 Local AI（**取り込み担当・Ollama**） | OCR下書き生成（`_ocr_out/` のみ）、音声メモ文字起こし→インボックス投入 | vault本体（`_ocr_out/` 以外）への一切の書き換え／代筆／外部送信。※夜間QAループは 2026-07-02 廃止 → 後継は vault_lint.py（Python・決定的） |

## AI社員の3要素

各エージェントは以下3つの組み合わせで成立。どれかが欠けると機能しない。

- 📜 **マニュアル（指示書）** — 何をする／しないか、どう判断するか。各エージェントの instructions に書く。このイントラを必ず参照させる
- 🧠 **脳（モデル）** — タスクの難易度に応じて使い分ける（→ [[🛠 Technical Setup]] §モデル戦略）
- 🪑 **机（文脈環境）** — 独立したスレッドで動かす。1スレッドに複数タスクを混ぜない
