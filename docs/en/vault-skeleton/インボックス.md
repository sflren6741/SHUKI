# 📥 Inbox

> Drop anything in here. `@orchestrator` sorts it periodically, fills in the frontmatter, and moves the content to where it belongs (task / log / knowledge / project).
> Only set `status: done` once the content has actually been carried over. The question is not "should I delete this?" but "has this been moved yet?".

```base
filters:
  and:
    - file.inFolder("01_Inbox/インボックス")
views:
  - type: table
    name: 📥 Unprocessed
    filters:
      and:
        - status.containsAny("new", "routing")
    groupBy:
      property: status
      direction: ASC
    order:
      - file.name
      - status
      - type
      - area
      - created
    sort:
      - property: created
        direction: DESC
  - type: table
    name: ⏸ On hold
    filters:
      and:
        - status.containsAny("on-hold", "pending")
    order:
      - file.name
      - type
      - area
      - created
    sort:
      - property: created
        direction: ASC
  - type: table
    name: 📋 Everything
    groupBy:
      property: status
      direction: ASC
    order:
      - file.name
      - status
      - type
      - area
      - created
    sort:
      - property: created
        direction: DESC
```
