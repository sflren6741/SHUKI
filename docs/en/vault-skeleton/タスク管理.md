# ✅ Tasks

> One file per task (under `タスク管理/タスク/`). A task with `ai_judgment_ok: true` and `completion_criteria` filled in can be executed autonomously by an agent.
>
> The folder names stay in Japanese on purpose — the bundled scripts address them by path. Treat them as internal IDs; everything you read and write is in your own language.

```base
filters:
  and:
    - file.inFolder("04_Tasks/タスク管理/タスク")
    - status != "archived"
views:
  - type: table
    name: 🗂 Active
    filters:
      and:
        - status.containsAny("todo", "in-progress")
    groupBy:
      property: status
      direction: ASC
    order:
      - file.name
      - status
      - priority
      - due
      - area
      - agent
    sort:
      - property: priority
        direction: DESC
      - property: due
        direction: ASC
  - type: table
    name: 📅 Due this week
    filters:
      and:
        - due <= date(today, 7)
        - status != "done"
        - status != "cancelled"
    order:
      - file.name
      - status
      - priority
      - due
      - area
    sort:
      - property: due
        direction: ASC
      - property: priority
        direction: DESC
  - type: table
    name: 🤖 By agent
    filters:
      and:
        - status.containsAny("todo", "in-progress", "on-hold")
    groupBy:
      property: agent
      direction: ASC
    order:
      - file.name
      - status
      - priority
      - due
      - ai_judgment_ok
    sort:
      - property: priority
        direction: DESC
      - property: due
        direction: ASC
  - type: table
    name: 📋 Everything
    order:
      - file.name
      - status
      - priority
      - due
      - area
      - agent
    sort:
      - property: status
        direction: ASC
      - property: due
        direction: ASC
```
