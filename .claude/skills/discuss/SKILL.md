# 💬 ディスカッション（思考の壁打ちスキル）

## 起動方法

- `/discuss <テーマ>` — テーマ指定で開始（例: `/discuss 転職のキャリアパス`）
- `/discuss` — テーマなしで開始 → 最初に「何について考えたい？」と聞く

## 🧭 必読コンテキスト

開始前に以下を読む：

- `00_Intranet/AI運用ルール集（イントラ）/🪪 Identity.md`
- `00_Intranet/AI運用ルール集（イントラ）/哲学・価値観.md`
- `00_Intranet/AI運用ルール集（イントラ）/デザイン言語.md`

---

## 🎯 このスキルの目的

**発散フェーズ専用。収束させない。**

- 答えを出すのではなく、問いを広げる
- 評価・判断・優先順位づけは後でいい
- 「とりあえずここに出しておく」場所

---

## フロー

### ① テーマの確認

テーマが渡されていれば：
- 「『〈テーマ〉』について考えたいんですね。今どんな状態から始めますか？（考えが固まってる？まだぼんやり？）」

テーマがなければ：
- 「何について考えたい？できるだけ自由に話してください。」

### ② 発散フェーズ（メイン）

問いを3つ返す形式で進める。1問1問答えてもらいながら進める。

**問いの原則**：
- オープン型（はい/いいえで終わらない）
- 仮定を外す（「もし○○がなかったら？」「正反対だったら？」）
- 視点を変える（「10年後の自分から見ると？」「他の人はどう見る？」）
- 決断を求めない（「どちらが良いですか」はしない）

**一例**：
- 「この話の中で、一番エネルギーを感じる部分はどこ？」
- 「今一番のブレーキになってるものは？」
- 「逆に、うまくいっている前提で話すとしたら？」

### ③ まとまりの確認

「そろそろ整理してみますか？」と聞き、Yes なら：
- 出てきたキーワード・テーマをリストアップ
- 「重なっていること」「対立していること」「まだ触れていないこと」を整理

### ④ セッション末の選択肢（必ず提示）

```
このセッションをどうしますか？

A) インボックスに要約を投げる（01_Inbox/）
B) /plan に引き継いで構造化する
C) このまま終了（記録なし）
```

**A を選んだ場合**：

```markdown
---
title: "discuss-YYYY-MM-DD-<テーマスラグ>"
type: 📝メモ
status: new
area: <対象 Area>
date: YYYY-MM-DD
created: YYYY-MM-DD
---

# 💬 discuss セッション要約 — <テーマ>（YYYY-MM-DD）

## 出てきたキーワード・論点
- <キーワード1>
- <キーワード2>

## まだ答えが出ていない問い
- <問い1>
- <問い2>

## 気づき（もしあれば）
- <気づき>

## 次のアクション（任意）
- <タスクや引き継ぎ先>
```

`01_Inbox/インボックス/discuss-YYYY-MM-DD-<テーマスラグ>.md` に Write で保存。

---

## 代筆禁止の継承

- パートナーへのメッセージ・手紙の代筆はこのスキルでもしない
- 非公開Areaについての壁打ちは可。ただし「どう伝えるか」の文章生成はしない

- アンチスロップ: <「素晴らしいアイデアですね」等のフィラーが混入していないか>
