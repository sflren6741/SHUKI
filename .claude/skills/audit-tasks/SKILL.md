# 🧹 タスク棚卸（対話型）

タスクDB（`04_Tasks/タスク管理/タスク/`）を点検し、**検出はAI・判断はユーザー**で一つずつ片付ける。infrastructure エージェントは Read 中心の検出専門だが、このスキルは**会話で決めて、その場で更新まで**行う。

## 🧭 必読コンテキスト
- `00_Intranet/AI運用ルール集（イントラ）/✅ タスク管理ルール.md`（status・担当者・完了条件の定義）
- `00_Intranet/AI運用ルール集（イントラ）/🗂 vault構造ガイド.md` §📂 タスクDBの扱い方
- `06_Resources/Resources/概念/フォーカス・ファネル（時間を増やす原則）.md`（Eliminate → Automate → Delegate → Concentrate / 意図的な先延ばし）

## 🔄 フロー

### Step 1: スキャン
`04_Tasks/タスク管理/タスク/*.md` を Glob 全取得し、frontmatter（status / due / priority / created / agent）を抽出して分類：
- 🔴 **期限切れ**: due < 今日 かつ status が未完了
- 🟡 **停滞**: 7日以上更新なし（created/履歴の最終日付基準）かつ未完了
- 🔁 **重複・分裂**: タイトル類似・同テーマの複数ファイル
- 🔗 **参照切れ**: 削除済みエージェント名や存在しないwikilink先

### Step 2: ファネル判定 → 提示（一覧 → 1件ずつ）
まず件数サマリを出す。次に各タスクを**フォーカス・ファネル**に上から順にかけて推奨を作る：
1. **Eliminate** — そもそもまだやる価値があるか？ 状況が変わった・重要性が低い → **やらない（`status: archived`）** を提案
2. **Automate / Delegate** — AIに任せられるか？ → `agent`（Tier A）の設定を提案（12:30ディスパッチ便が拾う）。`human_only` が立っていれば外すかを聞く
3. **今やるべきか？** — No なら **start 設定（意図的な先延ばし）**：`start` を再開日に設定し🎯ビューから消す。Yes なら継続（due・next_action を整える）

**1件ずつ**「現状 → 推奨アクション」を提示してユーザーに聞く：
```
🔴 [[タスク名]] — 期限 2026-05-10（21日超過）
  推奨: やらない(archived) / start設定(意図的先延ばし) / AI委任 / 延期 / 分解 / 完了扱い / 削除 / 保留 — どれにする？
```
- 1ターンで数件まで。一気に全部出して圧倒させない
- 推奨は出すが、決めるのはユーザー
- **start と on-hold の使い分け**: start ＝ 自分の決断で「この日まで待つ」（再開日が決まっている）／ on-hold ＝ 外部要因待ち（再開日が自分で決められない）

### Step 3: 決定を反映（ユーザーの指示後のみ）
ユーザーが決めたものだけ更新する：
- **やらない（Eliminate）**: `status: archived`、`## 履歴` に「やらないと決めた理由」を1行（削除ではなく決断の記録。ビューからは自動で消える）
- **start設定（意図的先延ばし）**: `start: YYYY-MM-DD` を設定、`## 履歴` に1行。status は todo のまま
- **AI委任**: `agent: <担当>` を設定（`human_only` があれば削除。既定は未記入＝AI可）
- **延期**: `due` を更新、`## 履歴` に1行
- **分解**: 子タスクを新規作成（parent wikilink を張る）、元タスクにリンク
- **完了**: `status: done`＋履歴（※ユーザーの明示指示がある時だけ。勝手に完了にしない）
- **削除**: ユーザーが「削除」と明言した場合のみ。まず内容を見せて確認
- **保留/エスカレーション**: `agent: 人間（ユーザー）`＋`human_only: true`

### Step 4: 報告
処理サマリ（点検N件・更新M件・削除K件）を**チャットで報告**する。ファイルログは作らない（2026-07-02 .log一本化・手動スキルはチャット自体が記録）。

セッション終了時、`<data>/system/skill-runs.jsonl` に1行 append する（このスキルは生成物を残さないため、これが唯一の実行記録＝SHUKIダッシュボードのスキル推奨バッジ用。書式: `{"ts":"YYYY-MM-DD HH:MM","skill":"audit-tasks","source":"skill"}`）。

## 🚫 やってはいけないこと
- ❌ ユーザーの指示なくタスクを削除・完了・統合する（検出と提案まで）
- ❌ 「たぶん停滞」で判定する（必ず日付を確認）
- ❌ センシティブなタスク（代筆禁止ゾーン）の中身に踏み込んだ助言をする（棚卸し対象としての扱いのみ）
- ❌ 一度に大量提示して判断を急かす

## 🔄 セルフQAの3行
```
- 事実チェック: <期限・停滞は日付に基づくか。削除/完了はユーザーの明示指示があったか>
- トーン: <提案ベース・1件ずつ・急かさないか>
- アンチスロップ: <推測停滞・過剰削除提案がないか>
```
