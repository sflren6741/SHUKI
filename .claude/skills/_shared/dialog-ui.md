# 対話UIの使い分け（スキル共通）

スキルの「ユーザーに聞く／承認をもらう」手順はこのファイルの部品で書く。各 SKILL.md には部品名だけを書き、書式はここを正とする（2026-10-14 新設）。

## どこで動いているか

| 実行場所 | 見分け方 | 聞き方 |
|---|---|---|
| **ダッシュボードの対話パネル**（主経路） | system prompt に `NTFY_CHOICES` の規約がある | 下表の部品。**`AskUserQuestion` は使えない**（`claude -p` では一覧に無い・2026-10-14 実測。Codex も同様） |
| ターミナルの Claude Code | 上の規約が無い | `AskUserQuestion` でよい。GCal は MCP で、ユーザーの明示承認後に書く |

迷ったら対話パネル側の書き方にする（ターミナルでも文字として読めて壊れない）。

## 部品（対話パネル）

| 部品 | 使う時 | 書式 |
|---|---|---|
| **選択肢** | 判断が1つ・選択肢が有限 | 回答末尾に1行 `NTFY_CHOICES: 案A（推奨）\|案B\|案C`（2〜3個）。ボタンになり、押すとその文言がユーザー発言として届く |
| **複数の問い** | 互いに独立した判断が2〜4個 | 1判断1行 `NTFY_QUESTION: 観点\|案1\|案2\|案3`（各2〜4個）。1枚ずつ選んで最後にまとめて届く。「その他（自由記述）」はパネルが自動で付ける |
| **予定カード** | GCal に入れる予定を承認してもらう | ` ```shuki-action ` ブロックに `{"type":"calendar","events":[{"title","date":"YYYY-MM-DD","start":"HH:MM","end":"HH:MM","location","description"}]}`（start/end 省略で終日・最大12件） |
| **タスクカード** | タスクDBに1件起票してよいか承認してもらう | ` ```shuki-action ` ブロックに `{"type":"task","title","area","due","next_action","completion_criteria","parent","reason"}` |
| 図・マインドマップ | 構造や流れを見せる時だけ | ` ```mermaid ` ／ ` ```markmap `（入れ子リスト。マインドマップは必ずこちら） |
| 強調 | 見落とすと困る1〜2点・1つの注意 | `==ハイライト==`（1回答2つまで）／`> [!warning] 見出し` |
| ファイルへのリンク | 作った・参照したvaultファイルを開かせる | `[表示名](/files?p=<vault相対パスをURLエンコード>)` |

### カードの約束

- カードは**提案するだけ**。登録・作成はユーザーがボタンを押した時にサーバーが行う。AI は同じ予定を MCP で書いたり、同じタスクファイルを自分で作ったり、「登録しました」と書いたりしない。
- ユーザーはカード上で日時・タイトル・Area 等を直してから押せる。予定カードは同じ日の既存予定との重なりを自分で調べて表示するので、AI が空き確認を省いてよいわけではないが、重なりの最終確認はカードに任せてよい。
- 押した結果を受けて次の手順に進む必要がある時だけ `"followup": true` を付ける（結果がユーザー発言として届く）。付けなければ会話は止まったまま。
- タスクカードで `completion_criteria` を空にすると `human_only: true` で作られる（AGENTS.md ルール5）。
- 1回答につき予定カード1枚・タスクカード1枚まで。複数タスクを起票したい時は、まず選択肢で絞るか、1件ずつ出す。

## 聞き方の原則

- **有限の答えは打たせない**。「どれにしますか？」を地の文で書いて終わらず、選択肢かカードにする。自由記述が要る時（気持ち・出来事・言葉そのもの）だけ地の文で問う。
- **1ターン1問**。独立した判断が複数ある時だけ「複数の問い」を使う。
- **推奨を先頭に**、末尾に（推奨）。選択肢の文言に判断材料を入れてよい（文字数制限なし）。
- 確認が要らない回答には選択肢行もカードも付けない。
- ダッシュボードではセルフQAの3行を付けない（AGENTS.md ルール6）。各スキルの「セルフQA」節はターミナル実行時の指示。
- **代筆禁止ゾーン・お金・外部送信**の境界は部品を使っても変わらない。カードで扱えるのは GCal 登録とタスク起票だけで、メール送信・発注・支払いはカードにしない。
